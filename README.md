# STATE//LESS

> SIGNAL STRIKE — MORI의 코어를 지키는 60초 리플렉스 아케이드. 누군가 당신인 척 코어에 가짜 신호를 흘려보낸다. 화면 속 6개 슬롯에 무작위로 켜지는 신호 중 가짜만 사라지기 전에 정화하고, 진짜는 그대로 흘려보내야 한다.

`STATE//LESS`는 별도 서버나 API 키 없이 실행되는 정적 웹 게임입니다. 신호가 등장하는 간격·지속시간·동시 개수는 브라우저 안의 결정적 규칙 엔진이 경과 시간만으로 계산합니다. 첫 방문에는 게임 상태 쿠키의 보존 기간을 직접 고르고, 이후 방문부터는 방문 횟수·완료 런·보존 정책·이전 결말·최고 점수·기억 조각이 MORI의 대사와 다음 도전 목표에 반영됩니다.

## 플레이

- 온라인 플레이: <https://softkleenex.github.io/state-less-game/>

- 목표: 화면 속 6개 슬롯 중 무작위 위치에 켜지는 신호를 60초 동안 처리합니다. rose `✕`(가짜)는 사라지기 전에 클릭·탭하거나 번호 키(1~6)로 정화하고, cyan `◆`(진짜)는 그대로 흘려보냅니다.
- 난이도 곡선: 시간이 지날수록 신호 등장 간격(900ms→340ms)과 지속시간(1.45초→0.7초)이 짧아지고 동시에 켜지는 신호 수(1개→최대 4개)가 늘어납니다. 진짜/가짜를 구분하는 방법은 끝까지 색과 기호 하나로 동일합니다 — 판단이 아니라 반응 속도와 동시 처리 부담만 올라갑니다.
- 판정 차이: 가짜를 정화하면 점수·콤보가 오릅니다. **진짜를 오클릭하면 코어 무결성이 줄고 콤보가 끊기지만, 가짜를 그냥 놓치면 콤보만 끊기고 무결성은 그대로입니다** — 잘못 누른 것과 못 본 것을 구분해 좌절감을 줄입니다.
- 종료: 코어 무결성 3칸을 모두 잃으면 즉시 실패합니다. 60초를 채우면 정확도에 따라 랭크가 갈립니다.
- 성공: 오클릭 0회·정화 정확도 95% 이상이면 S랭크, 오클릭 1회 이하·정확도 80% 이상이면 A랭크로 `VERIFIED` 결말을 받아 다음 MORI 기억 파일과 조각 1개를 획득합니다.
- 성장: 기억 조각 2개마다 `ARCHIVE LENS` 충전이 늘어납니다. 사용하면 4초 동안 신호가 더 느리게 사라지며 런당 최대 3회 사용할 수 있습니다.
- 위험 선택: `DEEP VERIFY`를 켜면 5초 동안 정화 점수가 2배로 오르지만, 그 사이 오클릭하면 무결성 손실도 2배가 됩니다. 런당 한 번만 사용할 수 있습니다.
- 강화 선택: 7초 지점부터 6.5초 간격으로 반복해서(60초 런에 약 8회) 게임이 잠깐 멈추고 강화 카드 2장 중 1장을 고릅니다. 모든 강화는 순수 상승이 아니라 트레이드오프(예: 콤보 보너스 +50%지만 오클릭 손실 +1)이며, 46종 풀에서 매번 무작위로 2장이 제시됩니다. 같은 강화를 몇 번이든 다시 뽑아 효과를 무제한으로 쌓을 수 있는 것이 이 게임의 로그라이트 강화가 다른 게임들과 다른 지점입니다 — 슬롯 제한도, 교체도 없습니다.
- 난이도: 등장 간격·지속시간·동시 개수 곡선은 초반이 완만하다가 후반에 가팔라지도록 이징되어 있고, 그 위에 숨겨진 적응형 난이도(최근 성공/실수에 따라 ±12% 미세 조정)가 얹혀 있습니다. 진짜 첫 런에는 60초가 흐르기 전에 짧은 튜토리얼이 뜹니다.
- 런별 요청: 완료 런과 조각 수에 따라 `COMBO CHAIN`, `WAGER PROOF`, `CLEAN RUN`이 순환합니다. 목표 진행도를 한 판 내내 표시하고 완료 시 600점 보너스를 지급합니다.
- MORI: 1인칭 반말의 담담한 어조로 상황마다 다른 대사를 타이핑 효과와 함께 보여줍니다. 위험한 오클릭·아슬아슬한 클러치 정화 등 특정 상황마다 반응이 달라집니다.
- 결과 화면: 점수·랭크·이번 런에서 쌓은 강화 빌드 요약과 함께, 가장 아쉬웠던 실수 순간(시각·콤보·손실량)을 보여줍니다. 플레이 스타일(위험형/정밀형/신중형/속도형)에 따라 MORI의 대사 한 줄도 달라집니다.
- 재방문: 저장한 결말·최고 점수·연속 플레이일·성공으로 얻은 조각과 MORI 기록이 다음 방문의 대사와 도전 목표에 반영됩니다. 실패 기록은 남지만 조각은 지급되지 않습니다.
- 완성 후: 여섯 파일을 모두 복구하면 인트로 목표가 최고 점수 도전으로 전환됩니다.

### 키보드만 사용

- `1`~`6`: 같은 번호가 붙은 슬롯의 신호를 정화
- `D`: `DEEP VERIFY`를 5초 동안 걸기(런당 1회) · `F`: `ARCHIVE LENS`로 4초 동안 신호를 느리게(런당 2~3회)
- 시작·결말 화면에서도 방향키로 버튼을 이동하고 `Space` 또는 `Enter`로 실행할 수 있습니다.

### 마우스만 사용

- 신호가 켜진 슬롯을 클릭해 정화합니다.
- `ARCHIVE LENS`, `DEEP VERIFY`, 기억 정책, 결말 버튼도 클릭으로 조작합니다. 키보드 입력은 필요하지 않습니다.

두 입력 경로 모두 게임 시작부터 결말 선택과 재시작까지 다른 장치를 요구하지 않습니다. `prefers-reduced-motion` 환경에서는 가짜 신호의 점멸 애니메이션만 정지하며, 카운트다운 값과 판정 가능 여부는 동일하게 유지됩니다.

## 로컬 실행

Node.js 20.19 이상 또는 22.12 이상이 필요합니다. Node.js 24 사용을 권장합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소(기본값 `http://localhost:5173`)를 브라우저에서 엽니다.

```bash
npm test       # 순수 게임 로직·쿠키 직렬화 테스트 22개
npm run build  # dist/ 정적 배포본 생성
npm run preview
npm run docs:pdf  # docs/*.md를 각 스타일시트 기준 PDF로 재생성 (Pandoc 필요)
```

전체 검증은 다음 한 줄로 실행할 수 있습니다.

```bash
npm run check
```

> `scripts/record-game.mjs`(`npm run record`)는 이전 화면 구조를 자동 조작하도록 작성되어, 이후 여러 차례의 재설계로 DOM 구조가 바뀌면서 현재 실행할 수 없는 상태입니다. 재설계 검증은 헤드리스 브라우저로 직접 수행했습니다(`docs/AI_활용_기술.md` 참고). 제출용 플레이 영상은 자동 녹화 대신 실제 사람이 화면을 직접 녹화합니다.

## GitHub Pages 배포

이 폴더를 GitHub 저장소 루트로 사용하면 [deploy-pages.yml](.github/workflows/deploy-pages.yml)이 `main` 브랜치 푸시마다 테스트·빌드·배포를 수행합니다.

1. GitHub 저장소의 **Settings → Pages**에서 Source를 **GitHub Actions**로 선택합니다.
2. 이 폴더의 파일을 저장소 루트에 커밋하고 `main`으로 푸시합니다.
3. Actions의 `Deploy STATE LESS to GitHub Pages` 작업이 끝난 뒤 제공된 URL을 확인합니다.

Vite의 `base`를 상대 경로로 설정했으므로 사용자/프로젝트 Pages 경로 모두에서 정적 자산을 불러올 수 있습니다.

## 사용한 웹 기술

화면 아트 디렉션은 `MEMORY:// LOCAL ARCHIVE`입니다. 장식용 SF 터미널 대신 현재 게임 상태를 `memory://local/core/...`, `ending/...` 경로로 표시하고, 괘선·색인 카드·검수 표시가 쿠키와 기억 복구 규칙을 설명합니다.

- **Cookie Store API**: 게임 전용 1st-party 쿠키를 비동기로 읽고 씁니다. 미지원 환경에서는 `document.cookie`로 자동 전환합니다.
- **View Transition API**: 인트로·플레이·결말 화면을 문맥을 유지하며 전환합니다. 미지원 또는 움직임 감소 환경에서는 즉시 전환합니다.
- **Page Visibility API**: 플레이 도중 탭을 떠나면 60초 타이머와 신호 카운트다운을 함께 멈추고, 복귀 시 멈춘 시간만큼 모든 시각을 그대로 밀어 넣습니다.
- **CSS Container Queries**: 뷰포트가 아니라 게임 패널의 실제 크기에 맞춰 레이아웃을 다시 계산합니다.
- **반응형 타이포그래피**: `html { font-size: clamp(16px, 0.5vw + 13px, 19.5px); }` 한 줄로 모든 `rem` 텍스트가 창 너비에 비례해 커집니다. 좁은/모바일 화면은 기존 크기 그대로라 회귀가 없습니다.
- **Web Audio API**: 정화·오클릭·경보·콤보·결과 사운드는 오실레이터로 그 자리에서 합성합니다. 플레이 화면 배경 앰비언트 루프는 CC0 라이선스 외부 음원 1개(Freesound, 출처는 `docs/AI_활용_기술.md` §5 참고)를 사용하며, 코어 무결성에 따라 로우패스 필터로 먹먹해집니다.
- **requestAnimationFrame 게임 루프**: 별도 게임 엔진 없이 순수 DOM/CSS로 신호 스폰 스케줄링, 슬롯별 남은 시간 링, 난이도 곡선(등장 간격·지속시간·동시 개수)을 매 프레임 갱신합니다.

런타임에서 외부 AI 서버를 호출하지 않습니다. 신호의 종류와 등장 규칙은 현재 경과 시간과 검증 가능한 곡선 함수로 로컬에서 생성되어, 심사 중 네트워크 상태와 비용에 영향을 받지 않습니다.

## 개인정보와 쿠키

쿠키 이름은 `state_less_memory_v1`이며 다음 게임 데이터만 저장합니다.

- 방문 횟수
- 완료한 플레이 횟수
- 최고 점수
- 이전 결말
- 복구한 기억 조각 수(최대 6개)
- 연속 플레이일(하루 단위로만 갱신)
- 사용자가 고른 세션/7일 보존 정책

이름, 계정, 위치, 브라우징 기록 등 개인정보는 수집하거나 전송하지 않습니다. 결말 화면의 **쿠키를 지우고 처음으로** 버튼으로 언제든 게임 상태를 삭제할 수 있습니다.
