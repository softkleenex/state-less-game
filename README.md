# STATE//LESS

> 이 페이지는 당신을 기억한다. 누군가 당신인 척 이 브라우저에 들어오려 한다 — 세션 검증 AI MORI와 함께, 여러 사실이 결합된 세션 주장을 하나씩 심사해 진짜와 위조를 가려내는 심문관형 판단 게임.

`STATE//LESS`는 별도 서버나 API 키 없이 실행되는 정적 웹 게임입니다. MORI는 이 브라우저의 실제 상태(방문 기록·입력 기기·화면 상태 등)를 근거로 제시되는 세션 주장이 진짜 당신의 것인지, 위조된 주장인지, 판독 불가한지 검증합니다. 첫 방문에는 게임 상태 쿠키의 보존 기간을 직접 고르고, 이후 방문부터는 방문 횟수·완료 런·보존 정책·이전 결말·최고 점수·기억 조각이 세션 내용과 MORI의 대사에 반영됩니다.

## 플레이

- 온라인 플레이: <https://softkleenex.github.io/state-less-game/>

- 목표: 한 번에 하나씩 제시되는 세션 카드를 읽고, 제한 시간 안에 **진짜** · **가짜** · **손상** 중 하나로 판정합니다. 카드는 왼쪽 `MORI의 기록`(항상 사실)과 오른쪽 `이 세션의 주장`을 2~3줄 나란히 보여주며, 정확히 한 줄만 다르거나 읽을 수 없을 수 있어 모든 줄을 한 줄씩 대조해야 합니다.
- 판단 근거: 별도 참고 패널 없이, 세션 카드 자체가 `MORI의 기록`과 `이 세션의 주장`을 한 줄씩 짝지어 보여줍니다. 두 열이 갈라지는 지점을 직접 찾아내는 것이 판단의 전부입니다.
- 웨이브 진행: 총 6웨이브. 웨이브마다 처리할 세션 수·주장에 결합되는 사실 개수(2→3)·판독 불가 비율이 늘고 세션당 제한 시간은 짧아져, 후반으로 갈수록 더 빠르고 더 복잡한 판단이 필요합니다. 무결성이 0이 되면 그 자리에서 실패합니다.
- 판정 차이: **위조 세션을 진짜로 승인하면 `MEMORY INTEGRITY`가 2칸, 진짜 세션을 위조로 오인하면 1칸 줄고 연속 기록이 끊깁니다** — 위조를 통과시키는 실수가 더 무겁습니다. 세션을 그냥 흘려보내는 것(놓침)은 연속 기록만 끊길 뿐 무결성은 깎이지 않습니다.
- 성공: 6웨이브 중 5개 이상을 클리어해 `VERIFIED` 결말에 도달하면 다음 MORI 기억 파일과 조각 1개를 획득합니다.
- 성장: 기억 조각 2개마다 `ARCHIVE LENS` 충전이 늘어납니다. 렌즈는 웨이브당 한 번, 지금 세션의 실제 판정을 미리 보여주며 런당 최대 3회 사용할 수 있습니다.
- 위험 선택: 답에 확신이 있으면 `DEEP VERIFY`를 켜 다음 판정 한 번에 보너스 350점을 걸 수 있습니다. 마지막 6번째 웨이브 `FINAL CORE`에서는 보너스가 700점으로 오르며, 그 판정이 오답이면 무결성을 2칸 잃습니다. 무결성이 1칸일 때는 켤 수 없습니다.
- 컴백: 오답 뒤 3연속 정답을 만들면 `SYNC RECOVERY`가 이전 오류 하나와 무결성 1칸을 복구합니다. 런당 한 번만 발동하며 복구 런의 최고 랭크는 A입니다.
- 런별 요청: 완료 런과 조각 수에 따라 `SYNC CHAIN`, `WAGER PROOF`, `CLEAN ARCHIVE`가 순환합니다. 목표 진행도를 한 판 내내 표시하고 완료 순간 MORI의 `REQUEST SEALED` 반응과 600점 보너스를 지급합니다.
- 결과 화면: 점수·랭크와 함께, 이번 런을 어떻게 플레이했는지(회복형/위험형/정밀형/속도형)에 따라 MORI의 대사 한 줄이 달라집니다.
- 재방문: 저장한 결말·최고 점수·성공으로 얻은 조각과 MORI 기록이 다음 플레이의 세션과 대사에 반영됩니다. 실패 기록은 남지만 조각은 지급되지 않습니다.
- 완성 후: 여섯 파일을 모두 복구하면 인트로 목표가 다음 파일에서 최고 점수와 6연속 SYNC 도전으로 전환됩니다.

### 키보드만 사용

- `1` / `2` / `3`: 지금 세션을 각각 **진짜** / **가짜** / **손상**으로 판정
- `D`: `DEEP VERIFY`를 다음 판정 한 번에 걸기(웨이브당 1회) · `F`: `ARCHIVE LENS`로 지금 세션의 실제 판정 확인
- 판정 후 `Space` / `Enter`: 자동 진행을 기다리지 않고 다음 웨이브로 이동
- 시작·결말 화면에서도 방향키로 버튼을 이동하고 `Space` 또는 `Enter`로 실행할 수 있습니다.

### 마우스만 사용

- **진짜**/**가짜**/**손상** 구역 버튼을 클릭해 지금 세션을 판정합니다.
- 원하는 기억 방식, `DEEP VERIFY`, `ARCHIVE LENS`, 결말 버튼도 클릭으로 조작합니다. 키보드 입력은 필요하지 않습니다.

세션 카드는 원래도 흐르거나 움직이지 않는 정적 레이아웃이라, 두 입력 경로 모두 `prefers-reduced-motion` 환경에서 별도 분기 없이 동일하게 동작합니다.

## 로컬 실행

Node.js 20.19 이상 또는 22.12 이상이 필요합니다. Node.js 24 사용을 권장합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소(기본값 `http://localhost:5173`)를 브라우저에서 엽니다.

```bash
npm test       # 순수 게임 로직 테스트
npm run build  # dist/ 정적 배포본 생성
npm run preview
```

전체 검증은 다음 한 줄로 실행할 수 있습니다.

```bash
npm run check
```

> `scripts/record-game.mjs`(`npm run record`)는 이전 화면 구조(정적 4지선다 + 확정 미터)를 자동 조작하도록 작성되어, 현재 SESSION AUDIT DOM 구조와 맞지 않아 실행할 수 없는 상태입니다. 새 화면 구조에 맞춘 재작성은 아직 진행하지 않았습니다 — 재설계 검증은 헤드리스 브라우저로 직접 수행했습니다(`docs/AI_활용_기술.md` 참고).

## GitHub Pages 배포

이 폴더를 GitHub 저장소 루트로 사용하면 [deploy-pages.yml](.github/workflows/deploy-pages.yml)이 `main` 브랜치 푸시마다 테스트·빌드·배포를 수행합니다.

1. GitHub 저장소의 **Settings → Pages**에서 Source를 **GitHub Actions**로 선택합니다.
2. 이 폴더의 파일을 저장소 루트에 커밋하고 `main`으로 푸시합니다.
3. Actions의 `Deploy STATE LESS to GitHub Pages` 작업이 끝난 뒤 제공된 URL을 확인합니다.

Vite의 `base`를 상대 경로로 설정했으므로 사용자/프로젝트 Pages 경로 모두에서 정적 자산을 불러올 수 있습니다.

## 사용한 웹 기술

화면 아트 디렉션은 `MEMORY:// LOCAL ARCHIVE`입니다. 장식용 SF 터미널 대신 현재 게임 상태를 `memory://local/ledger/...`, `audit/...`, `ending/...` 경로로 표시하고, 괘선·색인 카드·검수 표시가 쿠키와 기억 복구 규칙을 설명합니다.

- **Cookie Store API**: 게임 전용 1st-party 쿠키를 비동기로 읽고 씁니다. 미지원 환경에서는 `document.cookie`로 자동 전환합니다.
- **View Transition API**: 인트로·플레이·결말 화면을 문맥을 유지하며 전환합니다. 미지원 또는 움직임 감소 환경에서는 즉시 전환합니다.
- **Page Visibility API**: 플레이 도중 탭을 떠나면 시간을 멈추고, 그 사실을 다음 문제 상태에 반영합니다.
- **BroadcastChannel**: 같은 출처에서 게임을 두 탭에 열면 `OTHER SELF` 상태와 문제 내용이 바뀝니다.
- **ResizeObserver + CSS Container Queries**: 뷰포트가 아니라 게임 패널의 실제 크기에 맞춰 레이아웃을 다시 계산합니다.
- **Web Audio API**: 외부 음원 없이 선택·정답·오답 사운드를 실시간 합성합니다.

런타임에서 외부 AI 서버를 호출하지 않습니다. “AI의 추론”은 현재 브라우저 상태와 검증 가능한 규칙으로 로컬에서 생성되어, 심사 중 네트워크 상태와 비용에 영향을 받지 않습니다.

## 개인정보와 쿠키

쿠키 이름은 `state_less_memory_v1`이며 다음 게임 데이터만 저장합니다.

- 방문 횟수
- 완료한 플레이 횟수
- 최고 점수
- 이전 결말
- 복구한 기억 조각 수(최대 6개)
- 사용자가 고른 세션/7일 보존 정책

이름, 계정, 위치, 브라우징 기록 등 개인정보는 수집하거나 전송하지 않습니다. 결말 화면의 **쿠키를 지우고 처음으로** 버튼으로 언제든 게임 상태를 삭제할 수 있습니다.
