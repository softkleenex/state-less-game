## 진행 방식

상황별 그림은 `MORI_상황별_캐릭터_설계.md`의 고정 원본·마스킹 편집 순서를 따르되, 실제 생성 작업은 `MORI_이미지_제작_시트.md`에서 항목별로 진행한다.

1. `MORI_이미지_제작_시트.md`의 0번(모델 기준표)부터 순서대로 프롬프트를 이미지 생성기에 붙여넣는다.
2. 확정된 이미지를 지정된 경로(`images/master/`, `images/states/`)에 저장하고, 같은 문서의 "이미지" 자리에 삽입한다.
3. 1차분(모델 기준표 + 흉상 11종) 완료 후 일관성을 확인하고, 문서 하단의 2차 제작분 6종을 이어서 진행한다.

표정·동작 차분은 반드시 확정된 PNG 원본(또는 observing 흉상)을 기준 이미지로 첨부하고 얼굴, 체형, 의상, 색상, 머리 모양을 고정한 편집 방식으로 제작한다.
