# STATE//LESS 게임 소개

## 게임 제목과 한 줄 소개

**STATE//LESS — SIGNAL STRIKE: MORI의 코어를 지키는 60초 리플렉스 아케이드**

누군가 당신인 척 MORI의 코어에 가짜 신호를 흘려보냅니다. 화면 속 6개 슬롯에 무작위로 켜지는 신호 중 가짜만 사라지기 전에 재빨리 정화하고, 진짜는 그대로 흘려보내 60초 동안 코어를 지켜내는 반응속도 아케이드입니다.

## 게임 개요

`STATE//LESS`는 룸에 배치된 6개 슬롯 중 무작위 위치에 신호가 짧게(후반에는 1초 미만) 켜지는 60초 단일 런 게임입니다. 신호는 색과 기호로 즉시 구분됩니다 — rose `✕`는 가짜, cyan `◆`는 진짜입니다. 가짜는 사라지기 전에 클릭·탭하거나 번호 키(1~6)로 정화해야 하고, 진짜는 그대로 흘려보내야 합니다. 시간이 지날수록 신호가 더 자주, 더 짧게, 더 많이 동시에 켜져 — 무엇을 볼지 읽는 게 아니라 어디를 먼저 처리할지 순간적으로 결정하는 게 게임의 전부입니다.

게임은 외부 AI API를 호출하지 않습니다. 신호의 종류·등장 간격·지속시간은 브라우저 안의 결정적 규칙 엔진이 경과 시간만으로 계산하므로 오프라인에 가까운 환경에서도 같은 규칙으로 플레이할 수 있습니다.

화면은 `MEMORY:// LOCAL ARCHIVE`라는 브라우저 기억 보관소로 구성됩니다. 현재 상태는 `memory://local/core/...`, `ending/...` 경로로 표시되고 cyan 색인선, amber 보존 표시, rose 정정 표시가 게임 규칙과 직접 연결됩니다. 방문 횟수·최고 점수·이전 결말·기억 조각 같은 진행도는 쿠키에만 저장되어 재방문할 때마다 MORI의 대사와 다음 도전 목표에 반영됩니다.

인트로와 결과 화면에는 MORI의 큰 인물 파일을 표시합니다. 플레이를 시작하면 소개 영역이 접히고 게임 패널이 전용 화면으로 확장되며, 상시 상태 슬롯·짧은 대사·정화 순간의 MORI 반응이 이어집니다. 전신 기준표 1장과 다수의 상황별 흉상 이미지를 실제로 제작해 상태마다 서로 다른 표정·손짓·소품이 그대로 드러나며, 하나의 기준 원본에서 얼굴·머리핀·복장을 고정한 채 부분만 편집해 캐릭터 일관성을 지켰습니다.

## 플레이 목표

1. 런이 시작되면 6개 슬롯 중 무작위 위치에 신호가 하나씩 켜지기 시작합니다. 시간이 지날수록 동시에 켜지는 신호 수·등장 간격·지속시간이 모두 어려워집니다.
2. 슬롯에 뜬 신호가 rose `✕`(가짜)면 사라지기 전에 클릭하거나 그 슬롯의 번호 키를 눌러 정화합니다. cyan `◆`(진짜)는 아무것도 하지 않고 그대로 흘려보냅니다.
3. 가짜를 정화하면 점수와 콤보가 오릅니다. 진짜를 잘못 클릭하면(오클릭) 코어 무결성이 줄고 콤보가 끊깁니다. 가짜를 놓치면(시간 초과) 콤보만 끊기고 무결성은 그대로입니다 — "잘못 판단한 것"과 "미처 못 본 것"을 구분해 좌절감을 줄입니다.
4. 필요할 때 `ARCHIVE LENS`로 4초 동안 신호가 느리게 사라지게 하거나, `DEEP VERIFY`로 5초 동안 정화 점수를 2배로 걸되 오클릭 손실도 2배로 만듭니다.
5. 15초·30초·45초 지점마다 게임이 잠깐 멈추고 강화 카드 2장 중 1장을 고릅니다. 6종 강화가 3번의 선택에 걸쳐 겹치지 않게 나뉘어 제시되므로, 한 런에서 실제로 갖게 되는 강화는 항상 3개뿐이고 런마다 다른 조합이 됩니다.
6. 매 런 순환하는 `MORI REQUEST`의 콤보·위험 검증·클린 런 목표를 달성해 600점 보너스를 얻습니다.
7. 60초를 채우거나 코어 무결성이 0이 되면 런이 끝납니다. A랭크 이상으로 코어를 지켜내면 다음 MORI 기억 파일과 조각 1개를 획득합니다.
8. 재방문하며 최대 6개의 기억 조각을 모두 모읍니다.

시간이 지날수록 신호 등장 간격은 900ms에서 340ms까지, 신호 지속시간은 1.45초에서 0.7초까지 짧아지고, 동시에 켜지는 신호 수는 1개에서 최대 4개까지 늘어납니다. 진짜와 가짜를 구분하는 방법 자체는 처음부터 끝까지 색과 기호 하나로 동일합니다 — 판단의 난이도가 아니라 순수하게 반응 속도와 동시 처리 부담이 올라갑니다.

`CORE INTEGRITY`는 남은 무결성 3칸을 실시간으로 보여줍니다. 3칸을 모두 잃으면 런이 즉시 중단됩니다. 정화할수록 `COMBO`가 오르고 점수 보너스가 커지며, 4콤보부터 MORI가 `COMBO LINKED` 상태로 반응합니다.

`ARCHIVE LENS`는 조각 수에 따라 런당 2~3회 충전되며, 사용하면 4초 동안 새로 켜지는 신호와 지금 켜져 있는 신호 모두 더 느리게 사라집니다. `DEEP VERIFY`는 런당 한 번만 켤 수 있고, 켠 순간부터 5초 동안 정화 점수가 2배로 오르지만 그 사이 오클릭하면 무결성 손실도 2배가 됩니다.

강화는 전부 순수한 상승 효과가 아니라 트레이드오프입니다 — 예를 들어 `콤보 특화`는 콤보 보너스를 50% 늘리지만 오클릭 시 무결성을 추가로 1칸 더 잃게 하고, `안전한 손`은 오클릭 손실을 줄이는 대신 정화 점수 자체를 10% 깎습니다. 어떤 강화를 고르느냐에 따라 같은 60초 런도 "공격적으로 콤보를 쌓는 런"과 "무결성을 아끼는 안전한 런"처럼 다른 방식으로 흘러갑니다.

`MORI REQUEST`는 완료 런·조각 수에 따라 `COMBO CHAIN`(최고 콤보 ×8), `WAGER PROOF`(`DEEP VERIFY` 중 정화 3회), `CLEAN RUN`(`VERIFIED` + 오클릭 0회)이 순환합니다. 완료 시 +600점이 결과 화면에 표시됩니다.

## 조작 방법

시간이 지날수록 신호 등장 간격·지속시간·동시 개수는 달라지지만, 플레이어가 실제로 하는 일은 하나뿐입니다 — **"슬롯에 뜬 신호가 가짜(rose, ✕)면 사라지기 전에 정화하고, 진짜(cyan, ◆)면 그대로 둔다."** 규칙을 새로 배울 필요 없이 이 한 가지만 알면 60초 런 전체를 플레이할 수 있습니다.

1. 6개 슬롯 중 어디에 신호가 켜졌는지, 그리고 그 신호가 가짜인지 진짜인지 한눈에 확인합니다.
2. 가짜라면 사라지기 전에 클릭하거나 번호 키를 누릅니다. 여러 개가 동시에 켜졌다면 사라지는 게 더 급한 쪽부터 처리합니다.
3. 진짜는 아무 것도 하지 않고 흘려보냅니다.
4. 정화에 성공하면 즉시 점수와 콤보가 오릅니다. 진짜를 잘못 클릭하면 무결성이 줄고 콤보가 끊기며, 가짜를 놓치면 콤보만 끊깁니다.

### 키보드만으로 플레이

- `1`~`6`: 같은 번호가 붙은 슬롯의 신호를 정화(강화 선택 중에는 `1`/`2`가 카드 선택으로 전환됩니다)
- `D`: `DEEP VERIFY`를 5초 동안 걸기(런당 1회, 고위험·고보상) · `F`: `ARCHIVE LENS`로 4초 동안 신호를 느리게(런당 2~3회)
- 시작 화면의 기억 정책과 결말 화면의 선택도 같은 방식으로 조작합니다.

### 마우스만으로 플레이

- 신호가 켜진 슬롯을 클릭해 정화합니다.
- 화면의 `ARCHIVE LENS`, `DEEP VERIFY`, 강화 카드, 기억 정책, 결말 버튼도 모두 클릭으로 조작합니다.

두 입력 경로 모두 게임 시작부터 결말 선택과 재시작까지 다른 장치를 요구하지 않습니다. 슬롯 주위 링이 그 신호의 남은 시간을 표시하며, `prefers-reduced-motion` 환경에서는 가짜 신호의 점멸 애니메이션만 정지하고 카운트다운 값과 판정 가능 여부는 동일하게 유지됩니다.

## 종료 조건과 결말

- **검증 성공**: 60초를 다 채우고 오클릭 1회 이하·정화 정확도 80% 이상이면 A 랭크, 오클릭 0회·정확도 95% 이상이면 S 랭크로 `VERIFIED` 결말을 받고 새 기억 조각과 MORI 파일을 획득합니다.
- **불안정/실패**: 정확도가 낮으면 `UNSTABLE`(B/C 랭크), 코어 무결성이 0이 되면 `NULL` 랭크로 즉시 종료됩니다. 이 경우 새 조각은 지급되지 않습니다.
- **기억 결말**: 결과와 성공으로 얻은 기억 조각을 게임 쿠키에 남기고 다시 플레이합니다. 다음 방문의 MORI 대사와 `MORI REQUEST`에 이전 상태가 반영됩니다.
- **최종 기록**: 여섯 번째 조각을 얻으면 `MORI.LOG/06`과 `ARCHIVE COMPLETE` 경로가 열리고, 재접속 인트로는 최고 점수 도전으로 전환됩니다.
- **무상태 결말**: 게임 쿠키를 삭제하고 첫 방문 상태로 돌아갑니다.

## 실행 방법

### 온라인 플레이

- 플레이 링크: <https://softkleenex.github.io/state-less-game/>
- 플레이 영상: **업로드 후 YouTube URL 입력**

### 로컬 실행

Node.js 20.19 이상이 설치된 환경에서 다음 명령을 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시된 주소를 Chrome, Edge, Safari 또는 Firefox 최신 버전에서 엽니다. 최신 Cookie Store API가 없는 환경도 `document.cookie` 폴백으로 플레이할 수 있습니다.

## 데이터와 접근성

게임 쿠키에는 방문·완료 횟수, 점수, 결말, 조각, 보존 정책만 저장하며 개인정보·타 사이트 쿠키는 읽지 않습니다. 키보드·마우스 각각 단독으로 시작부터 결말까지 완주할 수 있습니다. 다만 60초 안에 여러 슬롯을 동시에 반응해야 하는 리플렉스 장르 특성상, 스크린 리더나 느린 입력 장치로는 완주 난이도가 높을 수 있습니다 — 판정 결과(정화·오클릭·놓침)는 음성으로 안내되지만, 신호가 어디에 켜졌는지를 실시간으로 파악하는 것 자체는 시각적 확인에 의존합니다. 탭 이탈 시 타이머와 신호 카운트다운을 모두 멈춰 부재중 불이익이 없습니다.
