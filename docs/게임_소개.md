# STATE//LESS 게임 소개

## 게임 제목과 한 줄 소개

**STATE//LESS — 이 페이지는 당신을 기억한다**

브라우저의 실제 상태를 근거로, 로컬 AI가 만든 세 문장 중 단 하나의 거짓 기억을 제한 시간 안에 지우는 메타 퍼즐 게임입니다.

## 게임 개요

웹은 본래 무상태(stateless)지만 쿠키는 방문자의 상태를 기억합니다. `STATE//LESS`는 이 모순을 게임의 서사와 규칙으로 사용합니다. 플레이어가 선택한 쿠키 보존 방식, 방문 횟수, 이전 결말, 첫 입력 장치, 탭 이탈 여부 등이 실제 문제로 등장합니다.

게임은 외부 AI API를 호출하지 않습니다. 브라우저 안의 결정적 규칙 엔진이 현재 상태를 근거로 진실 두 개와 거짓 하나를 생성하므로 오프라인에 가까운 환경에서도 같은 규칙으로 플레이할 수 있습니다.

## 플레이 목표

1. 라운드 상단의 실제 브라우저 상태를 확인합니다.
2. AI가 만든 세 문장 중 그 상태와 모순되는 문장 하나를 선택합니다.
3. 제한 시간이 끝나기 전에 거짓 문장을 지웁니다.
4. 최대 6개의 기억 패킷을 검증해 최종 랭크를 획득합니다.

오답 또는 시간 초과마다 `MEMORY INTEGRITY`가 1칸 줄어듭니다. 3칸을 모두 잃으면 감사가 즉시 중단됩니다. 빠른 정답과 연속 정답은 추가 점수를 제공합니다.

## 조작 방법

### 키보드만으로 플레이

- `←` / `→`: 선택 이동
- `Space` / `Enter`: 선택 확정
- 시작 화면의 기억 정책과 결말 화면의 선택도 같은 방식으로 조작합니다.

### 마우스만으로 플레이

- 기억 정책, 거짓 문장, 결말 버튼을 마우스로 클릭합니다.

두 입력 경로 모두 게임 시작부터 결말 선택과 재시작까지 다른 장치를 요구하지 않습니다.

## 종료 조건과 결말

- **성공**: 6개 패킷을 끝까지 검증하면 정답 수와 속도에 따라 S/A/B/C 랭크를 받습니다.
- **실패**: `MEMORY INTEGRITY`가 0이 되면 NULL 랭크로 종료됩니다.
- **기억 결말**: 결과를 게임 쿠키에 남기고 다시 플레이합니다. 다음 문제에 이전 결말이 등장합니다.
- **무상태 결말**: 게임 쿠키를 삭제하고 첫 방문 상태로 돌아갑니다.

## 실행 방법

### 온라인 플레이

- 플레이 링크: **배포 후 GitHub Pages URL 입력**
- 플레이 영상: **업로드 후 YouTube URL 입력**

### 로컬 실행

Node.js 20.19 이상이 설치된 환경에서 다음 명령을 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시된 주소를 Chrome, Edge, Safari 또는 Firefox 최신 버전에서 엽니다. 최신 Cookie Store API가 없는 환경도 `document.cookie` 폴백으로 플레이할 수 있습니다.

## 데이터와 접근성

- 게임 전용 1st-party 쿠키에는 방문 횟수·완료 횟수·최고 점수·이전 결말·보존 정책만 저장합니다.
- 개인정보나 다른 사이트의 쿠키를 읽지 않습니다.
- 모든 주요 흐름은 키보드 포커스와 스크린 리더 안내를 제공합니다.
- 운영체제의 움직임 감소 설정을 존중합니다.
- 탭을 떠나면 타이머를 멈추고 돌아왔을 때 문제를 다시 생성합니다.
