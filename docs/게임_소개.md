# STATE//LESS 게임 소개

## 게임 제목과 한 줄 소개

**STATE//LESS — 이 페이지는 당신을 기억한다**

누군가 당신인 척 이 브라우저에 들어오려 합니다. 세션 검증 AI `MORI`와 함께, 동시에 켜지는 여러 터미널 사이를 직접 오가며 접속한 세션의 주장을 심사해 진짜와 위조를 가려내고, 여섯 번의 감사로 MORI의 기억 조각을 복구하는 심문관형 판단 게임입니다.

## 게임 개요

웹은 본래 무상태(stateless)지만 쿠키는 방문자의 상태를 기억합니다. `STATE//LESS`는 이 모순을 MORI가 당신을 검증하는 기술적 근거로 사용합니다 — 방문 횟수, 이전 결말, 입력 기기, 화면 상태 같은 브라우저 신호는 오직 진짜 당신만 만들어낼 수 있는 흔적이고, 위조하려는 쪽은 이 신호들을 그럴듯하게 흉내낼 뿐입니다. 세션은 화면 속 룸에 배치된 여러 터미널에 무작위로 접속을 걸어 오며, 터미널마다 독립된 카운트다운이 함께 시작됩니다. 플레이어가 직접 조작하는 요원을 방향키로 움직여(또는 터미널을 클릭·탭해 자동 이동) 켜진 터미널에 도착해야만 그 세션의 카드가 열립니다 — 카드에는 `MORI의 기록`(항상 사실)과 `이 세션의 주장`(대부분 MORI의 기록과 같지만 정확히 한 줄만 다르거나 읽을 수 없음)이 나란히 2~3줄 제시되며, 두 기록을 한 줄씩 맞대어 보며 서로 달라지는 지점을 직접 찾아내야 합니다. 여러 터미널이 동시에 켜지는 웨이브에서는 어디부터 갈지 우선순위를 정하는 것 자체가 판단의 일부입니다 — 늦게 도착한 터미널은 판정할 기회조차 없이 시간이 끝나 "놓침"으로 넘어갑니다.

게임은 외부 AI API를 호출하지 않습니다. 브라우저 안의 결정적 규칙 엔진이 현재 상태로 세션 주장을 생성하므로 오프라인에 가까운 환경에서도 같은 규칙으로 플레이할 수 있습니다.

화면은 `MEMORY:// LOCAL ARCHIVE`라는 브라우저 기억 보관소로 구성됩니다. 현재 상태는 `memory://local/ledger/...`, `audit/...`, `ending/...` 경로로 표시되고 cyan 색인선, amber 보존 표시, rose 정정 표시가 게임 규칙과 직접 연결됩니다.

인트로와 결과 화면에는 MORI의 큰 인물 파일을 표시합니다. 플레이를 시작하면 소개 영역이 접히고 게임 패널이 전용 화면으로 확장되며, 상시 상태 슬롯·짧은 대사·판정 순간의 MORI 반응 컷인이 이어집니다. 전신 기준표 1장과 17개 상황별 흉상 이미지를 모두 실제로 제작해 상태마다 서로 다른 표정·손짓·소품이 그대로 드러나며, 하나의 기준 원본에서 얼굴·머리핀·복장을 고정한 채 부분만 편집해 캐릭터 일관성을 지켰습니다.

## 플레이 목표

1. 웨이브가 시작되면 룸에 배치된 터미널 중 일부가 무작위로 켜지며 각자 독립된 카운트다운을 시작합니다. 웨이브가 오를수록 동시에 켜지는 터미널 수가 늘어 우선순위 판단이 필요해집니다.
2. 방향키로 요원을 움직여(또는 터미널을 클릭·탭해 자동 이동) 켜진 터미널에 도착합니다. 도착하면 그 세션의 카드가 열립니다 — 왼쪽은 `MORI의 기록`, 오른쪽은 `이 세션의 주장`이며 2~3줄이 나란히 짝지어 있습니다.
3. 두 열을 한 줄씩 비교합니다. 모든 줄이 같으면 **진짜**, 한 줄이라도 다른 값으로 바뀌어 있으면 **가짜**, 한 줄이 "읽을 수 없다"류 표현이면 **손상**으로 판정합니다.
4. 그 터미널의 카운트다운 안에 세 구역 중 하나를 확정합니다. 도착하지 못해 카운트다운이 끝나면 그 세션은 놓치고 다음 세션이 같은 터미널에 이어서 켜지며, 웨이브가 요구하는 세션 수를 모두 처리하기 전에 무결성이 0이 되면 감사가 실패합니다.
5. 필요할 때 `ARCHIVE LENS`로 지금 세션의 실제 판정을 확인하거나 `DEEP VERIFY`로 이번 한 판정에 고위험·고보상을 겁니다. 마지막 웨이브는 2배 승부수가 열리는 `FINAL CORE`입니다.
6. 매 런 순환하는 `MORI REQUEST`의 연속 정답·위험 검증·무결성 목표를 달성해 600점 보너스를 얻습니다.
7. 6개 웨이브 중 5개 이상을 검증해 다음 MORI 기억 파일과 조각 1개를 획득합니다.
8. 재방문하며 최대 6개의 기억 조각을 모두 모읍니다.

웨이브가 진행될수록 처리할 세션 수·동시에 켜지는 터미널 수·주장에 결합되는 사실 개수·판독 불가 비율이 함께 늘고, 터미널당 제한 시간은 짧아집니다. 즉 후반 웨이브는 더 빨리 움직이며 우선순위를 정해야 하는 동시에 더 복잡한 주장(사실 2개→3개 결합)을 요구합니다 — 이동 속도와 판단 난이도가 함께 올라갑니다.

`VERIFIED GATE`는 여섯 웨이브의 성공·실패·현재 위치, 다음 `MORI.LOG` 보상과 이번 웨이브의 진행 상황을 실시간으로 보여줍니다. **위조 세션을 진짜로 승인하는 실수는 `MEMORY INTEGRITY`를 2칸 깎고, 진짜 세션을 위조로 오인하는 실수는 1칸만 깎습니다** — 위조를 통과시키는 쪽이 더 무거운 대가를 치릅니다. 3칸을 모두 잃으면 감사가 즉시 중단됩니다. 세션을 그냥 흘려보내는 것(놓침)은 연속 기록만 끊길 뿐 무결성은 깎이지 않습니다 — "잘못 판단한 것"과 "미처 못 본 것"을 구분해 좌절감을 줄입니다. 빠른 판정과 연속 정답은 추가 점수를 제공하며, 2연속부터 MORI가 `SYNC LINKED` 상태로 반응합니다. 실수 뒤 3연속 정답을 만들면 런당 한 번 `SYNC RECOVERY`가 이전 오류와 무결성 1칸을 복구해 닫힌 검증 가능성을 다시 엽니다. 복구 런은 S 대신 최대 A랭크를 받습니다.

`ARCHIVE LENS`는 지금 세션의 실제 판정(진짜/가짜/손상)을 잠깐 밝혀 보여주며, 웨이브당 1회·조각 수에 따라 런당 2~3회 충전됩니다. `DEEP VERIFY`는 무결성이 2칸 이상일 때만 웨이브당 1회 걸 수 있고, 다음 판정 한 번에 정답 +350점·실패 시 무결성 -2가 적용됩니다. 마지막 웨이브는 MORI의 `CORE EXPOSED` 상태로 바뀌며 `DEEP VERIFY` 정답 보너스가 +700점으로 상승합니다.

`MORI REQUEST`는 완료 런·조각 수에 따라 `SYNC CHAIN`(4연속 정답), `WAGER PROOF`(`DEEP VERIFY` 정답 2회), `CLEAN ARCHIVE`(`VERIFIED` + 종료 무결성 3칸)가 순환합니다. 완료 순간 `REQUEST SEALED` 컷인과 +600점이 표시되며 결과 화면에도 성공 여부가 남습니다.

## 조작 방법

웨이브마다 동시에 켜지는 터미널 수·결합되는 사실 개수·제한 시간이 달라지지만, 플레이어가 실제로 하는 일은 항상 두 가지뿐입니다 — **"켜진 터미널로 이동해 도착하고, MORI의 기록과 세션의 주장을 비교해 다른 한 줄을 찾아 진짜·가짜·손상 중 하나로 판정한다."** 규칙을 새로 배울 필요 없이 이 두 가지만 알면 여섯 웨이브 전부를 풀 수 있습니다.

1. 켜진 터미널로 요원을 이동시켜 도착합니다. 여러 개가 동시에 켜졌다면 카운트다운이 가장 급한 쪽부터 갑니다.
2. 도착하면 열리는 세션 카드의 두 열(`MORI의 기록` / `이 세션의 주장`)을 한 줄씩 비교합니다.
3. 판정 구역 버튼을 지정합니다.
4. 올바른 판정이면 즉시 점수와 연속 기록이 오릅니다. 틀린 판정은 무결성이 줄고 연속 기록이 끊기되, 위조를 진짜로 승인한 실수는 2칸, 진짜를 위조로 오인한 실수는 1칸을 잃습니다. 도착이 늦어 시간 안에 판정하지 못하면 연속 기록만 끊깁니다.

### 키보드만으로 플레이

- `방향키`: 요원 이동
- `1` / `2` / `3`: 지금 도킹된 세션을 각각 **진짜** / **가짜** / **손상**으로 판정
- `D`: `DEEP VERIFY`를 다음 판정 한 번에 걸기(웨이브당 1회, 고위험·고보상) · `F`: `ARCHIVE LENS`로 지금 세션의 실제 판정 확인(웨이브당 1회)
- 시작 화면의 기억 정책과 결말 화면의 선택도 같은 방식으로 조작합니다.

### 마우스만으로 플레이

- 켜진 터미널을 클릭·탭하면 요원이 그 터미널까지 자동으로 이동합니다.
- 도착 후 **진짜**/**가짜**/**손상** 구역 버튼을 클릭해 판정합니다.
- 화면의 기억 정책·두 전술·다음 웨이브·결말 버튼도 클릭으로 조작합니다.

두 입력 경로 모두 게임 시작부터 결말 선택과 재시작까지 다른 장치를 요구하지 않습니다. 도착한 세션 카드 자체는 고정된 정적 레이아웃이라 `prefers-reduced-motion` 환경에서도 추가 분기 없이 동일하게 작동하며, 카드 아래 줄어드는 막대와 터미널 주위 링이 각각 남은 시간을 표시합니다.

## 종료 조건과 결말

- **검증 성공**: 6개 웨이브 중 5개 이상 클리어하면 A/S 랭크와 `VERIFIED` 결말을 받고 새 기억 조각과 MORI 파일을 획득합니다. S는 무복구 완벽 런에만 주어집니다.
- **불안정/실패**: 클리어한 웨이브가 4개 이하이면 `UNSTABLE`, `MEMORY INTEGRITY`가 0이면 NULL 랭크로 종료됩니다. 이 경우 새 조각은 지급되지 않습니다.
- **기억 결말**: 결과와 성공으로 얻은 기억 조각을 게임 쿠키에 남기고 다시 플레이합니다. 다음 일지와 문제에 이전 상태가 등장합니다.
- **최종 기록**: 여섯 번째 조각을 얻으면 `MORI.LOG/06`과 `ARCHIVE COMPLETE` 경로가 열리고, 재접속 인트로는 최고 점수와 6연속 `SYNC` 도전으로 전환됩니다.
- **무상태 결말**: 게임 쿠키를 삭제하고 첫 방문 상태로 돌아갑니다.

## 실행 방법

### 온라인 플레이

- 플레이 링크: <https://softkleenex.github.io/state-less-game/>
- 플레이 영상: **업로드 후 YouTube URL 입력**

### 로컬 실행

Node.js 20.19 이상이 설치된 환경에서 다음 명령을 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시된 주소를 Chrome, Edge, Safari 또는 Firefox 최신 버전에서 엽니다. 최신 Cookie Store API가 없는 환경도 `document.cookie` 폴백으로 플레이할 수 있습니다.

## 데이터와 접근성

게임 쿠키에는 방문·완료 횟수, 점수, 결말, 조각, 보존 정책만 저장하며 개인정보·타 사이트 쿠키는 읽지 않습니다. 키보드·마우스 각각 단독으로 시작부터 결말까지 완주할 수 있고, 움직임 감소 환경에서는 터미널 점멸 애니메이션이 꺼지되 카운트다운 값 자체는 동일하게 갱신됩니다. 탭 이탈 시 타이머를 멈춥니다. 요원 이동은 화면 위 좌표를 보는 조작이라 스크린 리더로는 터미널 점등·판정 결과 안내만 음성으로 확인할 수 있고, 이동 자체의 시각적 확인은 어렵습니다.
