# STATE//LESS 게임 소개

## 게임 제목과 한 줄 소개

**STATE//LESS — SIGNAL STRIKE: MORI의 코어를 지키는 60초 리플렉스 아케이드**

누군가 당신인 척 MORI의 코어에 가짜 신호를 흘려보냅니다. 화면 속 6개 슬롯에 무작위로 켜지는 신호 중 가짜만 사라지기 전에 재빨리 정화하고, 진짜는 그대로 흘려보내 60초 동안 코어를 지켜내는 반응속도 아케이드입니다.

## 게임 개요

`STATE//LESS`는 6개 슬롯 중 무작위 위치에 신호가 짧게(후반에는 1초 미만) 켜지는 60초 단일 런 게임입니다. 신호는 색과 기호로 즉시 구분됩니다 — rose `✕`는 가짜, cyan `◆`는 진짜입니다. 시간이 지날수록 신호가 더 자주, 더 짧게, 더 많이 동시에 켜집니다 — 무엇을 볼지 읽는 게 아니라 어디를 먼저 처리할지 순간적으로 결정하는 게 게임의 전부입니다.

게임은 외부 AI API를 호출하지 않습니다. 신호의 종류·등장 간격·지속시간은 브라우저 안의 결정적 규칙 엔진이 경과 시간만으로 계산하므로, 오프라인에 가까운 환경에서도 같은 규칙으로 플레이할 수 있습니다.

화면은 `MEMORY:// LOCAL ARCHIVE`라는 브라우저 기억 보관소로 구성됩니다. 방문 횟수·최고 점수·이전 결말·기억 조각·연속 플레이일 같은 진행도는 쿠키에만 저장되어 재방문할 때마다 MORI의 대사와 다음 도전 목표에 반영됩니다. 인트로와 결과 화면에는 MORI의 큰 인물 파일을 표시하고, 플레이 중에는 상시 상태 슬롯과 상황별 짧은 대사가 이어집니다 — MORI는 1인칭 반말의 담담한 어조로 말하며, 강화를 고르거나 클러치(막판 정화)에 성공하는 등 특정 상황마다 다른 반응을 보입니다.

## 플레이 방법

### 핵심 규칙

시간이 지날수록 신호 등장 간격·지속시간·동시 개수는 달라지지만, 플레이어가 실제로 하는 일은 하나뿐입니다 — **"슬롯에 뜬 신호가 가짜(rose, ✕)면 사라지기 전에 정화하고, 진짜(cyan, ◆)면 그대로 둔다."** 규칙을 새로 배울 필요 없이 이 한 가지만 알면 60초 런 전체를 플레이할 수 있고, 진짜 첫 런에는 이 규칙을 보여주는 짧은 튜토리얼이 자동으로 뜹니다.

1. 6개 슬롯 중 어디에 신호가 켜졌는지, 그 신호가 가짜인지 진짜인지 한눈에 확인합니다.
2. 가짜라면 사라지기 전에 클릭하거나 번호 키를 누릅니다. 여러 개가 동시에 켜졌다면 사라지는 게 더 급한 쪽부터 처리합니다.
3. 진짜는 아무 것도 하지 않고 흘려보냅니다.
4. 정화에 성공하면 즉시 점수와 콤보가 오릅니다. 진짜를 잘못 클릭하면(오클릭) 무결성이 줄고 콤보가 끊기며, 가짜를 놓치면(시간 초과) 콤보만 끊깁니다 — "잘못 판단한 것"과 "미처 못 본 것"을 구분해 좌절감을 줄입니다.

### 자원과 로그라이트 강화

- `ARCHIVE LENS`(런당 2~3회): 4초 동안 신호가 느리게 사라지게 합니다.
- `DEEP VERIFY`(런당 1회 이상, 강화로 추가 가능): 5초 동안 정화 점수를 2배로 걸되 오클릭 손실도 2배가 됩니다.
- 7초 지점부터 6.5초 간격으로 게임이 잠깐씩 멈추고 강화 카드 2장 중 1장을 고릅니다(60초 런에 약 8회). 46종 강화 풀에서 매번 무작위로 2장이 제시되고, **같은 강화를 몇 번이든 다시 뽑아 효과를 무제한으로 쌓을 수 있습니다** — 보유 개수에 제한이 없는 것이 특징입니다. 모든 강화는 순수한 상승 효과가 아니라 트레이드오프입니다 — 예를 들어 `콤보 특화`는 콤보 보너스를 50% 늘리지만 오클릭 시 무결성을 추가로 1칸 더 잃게 합니다.
- 매 런 순환하는 `MORI REQUEST`의 콤보·위험 검증·클린 런 목표를 달성하면 600점 보너스를 얻습니다.

### 난이도

신호 등장 간격은 900ms에서 340ms까지, 지속시간은 1.45초에서 0.7초까지 짧아지고, 동시 신호 수는 1개에서 최대 4개까지 늘어납니다. 이 곡선은 초반이 급격하지 않도록 완만하게 시작해 후반에 가파르게 따라잡으며, 그 위에 최근 성공/실수에 따라 ±12% 범위로 미세 조정되는 숨은 적응형 난이도가 얹힙니다. 진짜와 가짜를 구분하는 방법 자체는 처음부터 끝까지 색과 기호 하나로 동일합니다 — 판단의 난이도가 아니라 순수하게 반응 속도와 동시 처리 부담이 올라갑니다.

### 조작 방법

**키보드만으로 플레이**
- `1`~`6`: 같은 번호가 붙은 슬롯의 신호를 정화(강화 선택 중에는 `1`/`2`가 카드 선택으로 전환됩니다)
- `D`: `DEEP VERIFY` 발동 · `F`: `ARCHIVE LENS` 발동
- 시작 화면의 기억 정책과 결말 화면의 선택도 같은 방식으로 조작합니다.

**마우스만으로 플레이**
- 신호가 켜진 슬롯을 클릭해 정화합니다.
- `ARCHIVE LENS`, `DEEP VERIFY`, 강화 카드, 기억 정책, 결말 버튼도 모두 클릭으로 조작합니다.

두 입력 경로 모두 게임 시작부터 결말 선택과 재시작까지 다른 장치를 요구하지 않습니다.

### 종료 조건과 결말

- **검증 성공**: 60초를 다 채우고 오클릭 1회 이하·정화 정확도 80% 이상이면 A 랭크, 오클릭 0회·정확도 95% 이상이면 S 랭크로 `VERIFIED` 결말을 받고 새 기억 조각과 MORI 파일을 획득합니다.
- **불안정/실패**: 정확도가 낮으면 `UNSTABLE`(B/C 랭크), 코어 무결성이 0이 되면 `NULL` 랭크로 즉시 종료됩니다. 이 경우 새 조각은 지급되지 않습니다.
- **결과 화면**: 점수·랭크와 함께 이번 런에서 쌓은 강화 빌드 요약, 가장 아쉬웠던 실수 순간(시각·콤보·손실량)을 보여줍니다.
- **재방문**: 결과로 얻은 기억 조각을 게임 쿠키에 남기고 다시 플레이합니다. 여섯 번째 조각을 얻으면 `MORI.LOG/06`과 `ARCHIVE COMPLETE` 경로가 열리고, 이후 재접속 인트로는 최고 점수 도전으로 전환됩니다. 게임 쿠키를 삭제하면 첫 방문 상태로 돌아갑니다.

## 실행 방법

### 온라인 플레이

- 플레이 링크: <https://softkleenex.github.io/state-less-game/>
- 플레이 영상: **업로드 후 YouTube URL 입력**

### 로컬 실행

Node.js 20.19 이상이 설치된 환경에서 다음 명령을 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시된 주소를 Chrome, Edge, Safari 또는 Firefox 최신 버전에서 엽니다. 최신 Cookie Store API가 없는 환경도 `document.cookie` 폴백으로 플레이할 수 있습니다.

## 데이터와 접근성

게임 쿠키에는 방문·완료 횟수, 점수, 결말, 기억 조각, 연속 플레이일, 보존 정책만 저장하며 개인정보·타 사이트 쿠키는 읽지 않습니다. 키보드·마우스 각각 단독으로 시작부터 결말까지 완주할 수 있습니다. 다만 60초 안에 여러 슬롯을 동시에 반응해야 하는 리플렉스 장르 특성상, 스크린 리더나 느린 입력 장치로는 완주 난이도가 높을 수 있습니다 — 판정 결과(정화·오클릭·놓침)는 음성으로 안내되지만, 신호가 어디에 켜졌는지를 실시간으로 파악하는 것 자체는 시각적 확인에 의존합니다. 탭 이탈 시 타이머와 신호 카운트다운을 모두 멈춰 부재중 불이익이 없고, `prefers-reduced-motion` 환경에서는 장식적 애니메이션이 꺼지되 판정에 필요한 정보(색상, 카운트다운 값)는 동일하게 유지됩니다.
