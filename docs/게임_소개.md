# STATE//LESS 게임 소개

## 게임 제목과 한 줄 소개

**STATE//LESS — 이 페이지는 당신을 기억한다**

브라우저 흔적을 해석해 기억 관리 AI `MORI`의 여섯 기억 조각을 복구하는 상태 기반 메타 퍼즐 게임입니다.

## 게임 개요

웹은 본래 무상태(stateless)지만 쿠키는 방문자의 상태를 기억합니다. `STATE//LESS`는 이 모순을 게임의 서사와 규칙으로 사용합니다. 플레이어는 브라우저 안에서 깨어난 MORI의 기억 관리자가 되어, 보존 정책·방문 횟수·완료 런·이전 결말·최고 점수·기억 조각과 브라우저 환경에서 생성된 14개 흔적을 복구합니다.

게임은 외부 AI API를 호출하지 않습니다. 브라우저 안의 결정적 규칙 엔진이 현재 상태로 간접 증거와 정답을 생성하므로 오프라인에 가까운 환경에서도 같은 규칙으로 플레이할 수 있습니다. Pretext는 증거 문장을 중앙 오염 코어 주위로 직접 흐르게 하고 화면 폭에 따라 새로 배치합니다.

화면은 `MEMORY:// LOCAL ARCHIVE`라는 브라우저 기억 보관소로 구성됩니다. 현재 상태는 `memory://local/ledger/...`, `audit/...`, `ending/...` 경로로 표시되고 cyan 색인선, amber 보존 표시, rose 정정 표시가 게임 규칙과 직접 연결됩니다.

인트로와 결과 화면에는 MORI의 큰 인물 파일을 표시합니다. 플레이를 시작하면 소개 영역이 접히고 게임 패널이 전용 화면으로 확장되며, 상시 상태 슬롯·짧은 대사·판정 순간의 MORI 반응 컷인이 이어집니다. 전신 기준표 1장과 17개 상황별 흉상 이미지를 모두 실제로 제작해 상태마다 서로 다른 표정·손짓·소품이 그대로 드러나며, 하나의 기준 원본에서 얼굴·머리핀·복장을 고정한 채 부분만 편집해 캐릭터 일관성을 지켰습니다.

## 플레이 목표

1. 오염 코어 주위로 흐르는 브라우저 증거 로그를 읽습니다.
2. `신호 해독`, `거짓 제거`, `진실 복구`, `색인 값 복원`, `교차 검증`, `체크섬 계산` 중 현재 라운드의 규칙을 확인합니다.
3. 제한 시간이 끝나기 전에 세 선택지 중 하나를 고릅니다.
4. 필요할 때 `ARCHIVE LENS`로 오답을 제외하거나 `DEEP VERIFY`로 추가 점수를 노립니다. 마지막 문제는 2배 승부수가 열리는 `FINAL CORE`입니다.
5. 매 런 순환하는 `MORI REQUEST`의 연속 정답·위험 검증·무결성 목표를 달성해 600점 보너스를 얻습니다.
6. 6개 중 5개 이상을 검증해 다음 MORI 기억 파일과 조각 1개를 획득합니다.
7. 재방문하며 최대 6개의 기억 조각을 모두 모읍니다.

기본 4개·고난도 2개 규칙은 난이도 구간을 유지한 채 세션 시드마다 순서가 달라집니다.

`VERIFIED GATE`는 여섯 라운드의 성공·실패·현재 위치, 다음 `MORI.LOG` 보상과 남은 정답 수를 실시간으로 보여줍니다. 0.1초 단위 타이머와 판정 컷인은 남은 시간·획득 점수·연속 정답·무결성 손실을 즉시 표시합니다. 일반 오답 또는 시간 초과는 `MEMORY INTEGRITY`를 1칸 줄이고, 3칸을 모두 잃으면 감사가 즉시 중단됩니다. 빠른 정답과 연속 정답은 추가 점수를 제공하며, 2연속부터 MORI가 `SYNC LINKED` 상태로 반응합니다. 실수 뒤 3연속 정답을 만들면 런당 한 번 `SYNC RECOVERY`가 이전 오류와 무결성 1칸을 복구해 닫힌 검증 가능성을 다시 엽니다. 복구 런은 S 대신 최대 A랭크를 받습니다. 남은 시간이 5초 이하가 되면 경고색·사운드·MORI 대사가 함께 바뀝니다.

`ARCHIVE LENS`는 오답 하나를 제외하며 조각 수에 따라 런당 1~3회 충전됩니다. `DEEP VERIFY`는 무결성이 2칸 이상일 때만 켤 수 있고 정답 +350점, 실패 시 무결성 -2입니다. 6라운드는 `audit/final-core-{rule}` 경로와 MORI의 `CORE EXPOSED` 상태로 바뀌며 `DEEP VERIFY` 정답 보너스가 +700점으로 상승합니다.

`MORI REQUEST`는 완료 런·조각 수에 따라 `SYNC CHAIN`(4연속 정답), `WAGER PROOF`(`DEEP VERIFY` 정답 2회), `CLEAN ARCHIVE`(`VERIFIED` + 종료 무결성 3칸)가 순환합니다. 완료 순간 `REQUEST SEALED` 컷인과 +600점이 표시되며 결과 화면에도 성공 여부가 남습니다.

## 조작 방법

라운드 종류(신호 해독·거짓 제거·진실 복구 등 6종)는 매번 다르지만, 플레이어가 실제로 하는 일은 항상 하나입니다 — **"지금 진짜인 신호를 고르고, 타이밍에 맞춰 SIGNAL LOCK으로 확정한다."** 규칙을 새로 배울 필요 없이 이 한 가지만 알면 여섯 라운드 전부를 풀 수 있습니다.

1. 후보 중 하나를 고릅니다.
2. 확정 입력을 누르면 좌우로 오가는 락 미터가 뜹니다.
3. 같은 입력을 다시 눌러 마커가 초록 구간 위에 있을 때 확정합니다 — 정중앙이면 **PERFECT LOCK**(보너스 점수), 구간 안이면 그대로, 구간 밖이면 정답이어도 보상이 절반으로 줄어듭니다.

### 키보드만으로 플레이

- `←` / `→`: 선택 이동
- `Space` / `Enter`: 1차 입력으로 후보를 고르고, 락 미터가 뜬 상태에서 같은 키를 다시 눌러 SIGNAL LOCK 확정
- `D`: `DEEP VERIFY` 켜기/끄기(락 미터 타깃이 좁아져 고위험·고보상이 됨) · `F`: `ARCHIVE LENS`로 오답 하나 제외
- 시작 화면의 기억 정책과 결말 화면의 선택도 같은 방식으로 조작합니다.

### 마우스만으로 플레이

- 후보를 클릭해 고르고, 락 미터가 뜬 상태에서 다시 클릭해 SIGNAL LOCK 확정합니다.
- 화면의 기억 정책·두 전술·다음 라운드·결말 버튼도 클릭으로 조작합니다.

두 입력 경로 모두 게임 시작부터 결말 선택과 재시작까지 다른 장치를 요구하지 않습니다. `prefers-reduced-motion` 환경에서는 락 미터 타이밍 단계를 건너뛰고 즉시 확정되어, 움직임에 민감한 플레이어도 동일하게 완주할 수 있습니다.

## 종료 조건과 결말

- **검증 성공**: 6개 중 5개 이상 정답이면 A/S 랭크와 `VERIFIED` 결말을 받고 새 기억 조각과 MORI 파일을 획득합니다. S는 무복구 완벽 런에만 주어집니다.
- **불안정/실패**: 정답이 4개 이하이면 `UNSTABLE`, `MEMORY INTEGRITY`가 0이면 NULL 랭크로 종료됩니다. 이 경우 새 조각은 지급되지 않습니다.
- **기억 결말**: 결과와 성공으로 얻은 기억 조각을 게임 쿠키에 남기고 다시 플레이합니다. 다음 일지와 문제에 이전 상태가 등장합니다.
- **최종 기록**: 여섯 번째 조각을 얻으면 `MORI.LOG/06`과 `ARCHIVE COMPLETE` 경로가 열리고, 재접속 인트로는 최고 점수와 6연속 `SYNC` 도전으로 전환됩니다.
- **무상태 결말**: 게임 쿠키를 삭제하고 첫 방문 상태로 돌아갑니다.

## 실행 방법

### 온라인 플레이

- 플레이 링크: <https://softkleenex.github.io/state-less-game/>
- 플레이 영상: **업로드 후 YouTube URL 입력**

### 로컬 실행

Node.js 20.19 이상이 설치된 환경에서 다음 명령을 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시된 주소를 Chrome, Edge, Safari 또는 Firefox 최신 버전에서 엽니다. 최신 Cookie Store API가 없는 환경도 `document.cookie` 폴백으로 플레이할 수 있습니다.

## 데이터와 접근성

게임 쿠키에는 방문·완료 횟수, 점수, 결말, 조각, 보존 정책만 저장하며 개인정보·타 사이트 쿠키는 읽지 않습니다. 키보드·스크린 리더·움직임 감소를 지원하고 탭 이탈 시 타이머를 멈춥니다.
