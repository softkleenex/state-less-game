# STATE//LESS 게임 소개

## 게임 제목과 한 줄 소개

**STATE//LESS — 이 페이지는 당신을 기억한다**

흐르는 브라우저 신호를 실시간으로 분류해 기억 관리 AI `MORI`의 여섯 기억 조각을 복구하는 시그널 트리아지 게임입니다.

## 게임 개요

웹은 본래 무상태(stateless)지만 쿠키는 방문자의 상태를 기억합니다. `STATE//LESS`는 이 모순을 게임의 서사와 규칙으로 사용합니다. 플레이어는 브라우저 안에서 깨어난 MORI의 기억 관리자가 되어, 보존 정책·방문 횟수·완료 런·이전 결말·최고 점수·기억 조각과 브라우저 환경에서 생성된 14개 흔적을 복구합니다.

게임은 외부 AI API를 호출하지 않습니다. 브라우저 안의 결정적 규칙 엔진이 현재 상태로 신호 텍스트(참/거짓/오염)를 생성하고, 그 신호들이 화면을 계속 가로질러 흐르는 실시간 웨이브로 배치되므로 오프라인에 가까운 환경에서도 같은 규칙으로 플레이할 수 있습니다.

화면은 `MEMORY:// LOCAL ARCHIVE`라는 브라우저 기억 보관소로 구성됩니다. 현재 상태는 `memory://local/ledger/...`, `audit/...`, `ending/...` 경로로 표시되고 cyan 색인선, amber 보존 표시, rose 정정 표시가 게임 규칙과 직접 연결됩니다.

인트로와 결과 화면에는 MORI의 큰 인물 파일을 표시합니다. 플레이를 시작하면 소개 영역이 접히고 게임 패널이 전용 화면으로 확장되며, 상시 상태 슬롯·짧은 대사·판정 순간의 MORI 반응 컷인이 이어집니다. 전신 기준표 1장과 17개 상황별 흉상 이미지를 모두 실제로 제작해 상태마다 서로 다른 표정·손짓·소품이 그대로 드러나며, 하나의 기준 원본에서 얼굴·머리핀·복장을 고정한 채 부분만 편집해 캐릭터 일관성을 지켰습니다.

## 플레이 목표

1. `TRIAGE LANE`으로 흐르는 증거 신호 칩을 실시간으로 지켜봅니다.
2. 각 칩을 `TRUE`(참) · `FALSE`(거짓) · `CORRUPTED`(판독 불가) 세 구역 중 신호가 실제로 속한 구역으로 옮깁니다. 칩이 주장하는 내용은 `LIVE SIGNAL` 패널(지금 이 브라우저의 실제 상태 14가지)과 바로 비교할 수 있어, 사전지식 없이도 그 자리에서 참·거짓을 판단할 수 있습니다.
3. 웨이브가 요구하는 목표 개수만큼 정확히 분류하면 웨이브가 끝나고, 목표를 못 채운 채 시간이 끝나거나 무결성이 0이 되면 실패합니다.
4. 필요할 때 `ARCHIVE LENS`로 현재 칩의 정답 구역을 잠깐 확인하거나 `DEEP VERIFY`로 5초간 고위험·고보상 구간을 엽니다. 마지막 웨이브는 2배 승부수가 열리는 `FINAL CORE`입니다.
5. 매 런 순환하는 `MORI REQUEST`의 연속 정답·위험 검증·무결성 목표를 달성해 600점 보너스를 얻습니다.
6. 6개 웨이브 중 5개 이상을 검증해 다음 MORI 기억 파일과 조각 1개를 획득합니다.
7. 재방문하며 최대 6개의 기억 조각을 모두 모읍니다.

웨이브가 진행될수록 목표 칩 개수와 동시 등장 개수, 판독 불가(`CORRUPTED`) 칩의 비율이 함께 늘어나 후반 웨이브일수록 손이 바빠집니다. 신호 내용 자체는 14개 흔적을 시드 기반으로 순환하지만, 매 웨이브 요구되는 조작은 항상 하나(칩 고르기 → 구역 지정)라 규칙을 새로 배울 필요가 없습니다.

`VERIFIED GATE`는 여섯 웨이브의 성공·실패·현재 위치, 다음 `MORI.LOG` 보상과 남은 목표 칩 수를 실시간으로 보여줍니다. 칩을 잘못된 구역에 넣으면 `MEMORY INTEGRITY`를 1칸 줄이고 연속 기록이 끊기며, 3칸을 모두 잃으면 감사가 즉시 중단됩니다. 반면 칩을 놓쳐 화면 밖으로 흘려보내는 것은 연속 기록만 끊길 뿐 무결성은 깎이지 않습니다 — "잘못 판단한 것"과 "미처 못 본 것"을 구분해 좌절감을 줄입니다. 빠른 분류와 연속 정답은 추가 점수를 제공하며, 2연속부터 MORI가 `SYNC LINKED` 상태로 반응합니다. 실수 뒤 3연속 정답을 만들면 런당 한 번 `SYNC RECOVERY`가 이전 오류와 무결성 1칸을 복구해 닫힌 검증 가능성을 다시 엽니다. 복구 런은 S 대신 최대 A랭크를 받습니다.

`ARCHIVE LENS`는 선택 중인(또는 가장 먼저 흘러온) 칩의 정답 구역을 잠깐 밝혀 보여주며, 웨이브당 1회·조각 수에 따라 런당 1~3회 충전됩니다. `DEEP VERIFY`는 무결성이 2칸 이상일 때만 웨이브당 1회 켤 수 있고, 활성화된 5초 동안 정답 +350점·실패 시 무결성 -2가 적용됩니다. 마지막 웨이브는 MORI의 `CORE EXPOSED` 상태로 바뀌며 `DEEP VERIFY` 정답 보너스가 +700점으로 상승합니다.

`MORI REQUEST`는 완료 런·조각 수에 따라 `SYNC CHAIN`(4연속 정답), `WAGER PROOF`(`DEEP VERIFY` 정답 2회), `CLEAN ARCHIVE`(`VERIFIED` + 종료 무결성 3칸)가 순환합니다. 완료 순간 `REQUEST SEALED` 컷인과 +600점이 표시되며 결과 화면에도 성공 여부가 남습니다.

## 조작 방법

웨이브 종류는 매번 늘어나는 속도·동시 등장 수·판독 불가 비율로 달라지지만, 플레이어가 실제로 하는 일은 항상 하나입니다 — **"흐르는 신호 칩을 하나 고르고, 그 신호가 속한 구역(TRUE/FALSE/CORRUPTED)으로 보낸다."** 규칙을 새로 배울 필요 없이 이 한 가지만 알면 여섯 웨이브 전부를 풀 수 있습니다.

1. `TRIAGE LANE`을 가로지르는 칩 중 하나를 고릅니다.
2. 그 칩이 속한 구역 버튼을 지정합니다.
3. 올바른 구역이면 즉시 점수와 연속 기록이 오르고, 틀린 구역이면 무결성이 줄고 연속 기록이 끊깁니다. 놓친 칩은 연속 기록만 끊깁니다.

### 키보드만으로 플레이

- `←` / `→`: 활성 칩 사이에서 선택 이동
- `1` / `2` / `3`: 선택한 칩을 각각 `TRUE` / `FALSE` / `CORRUPTED` 구역으로 확정
- `D`: `DEEP VERIFY` 5초 버스트 켜기(웨이브당 1회, 고위험·고보상) · `F`: `ARCHIVE LENS`로 선택한 칩의 정답 구역 확인(웨이브당 1회)
- 시작 화면의 기억 정책과 결말 화면의 선택도 같은 방식으로 조작합니다.

### 마우스만으로 플레이

- 칩을 클릭해 고르고, `TRUE`/`FALSE`/`CORRUPTED` 구역 버튼을 클릭해 확정합니다.
- 화면의 기억 정책·두 전술·다음 웨이브·결말 버튼도 클릭으로 조작합니다.

두 입력 경로 모두 게임 시작부터 결말 선택과 재시작까지 다른 장치를 요구하지 않습니다. `prefers-reduced-motion` 환경에서는 칩이 화면을 가로질러 흐르는 대신 고정된 세로 목록으로 쌓이고, 각 칩 옆의 너비가 줄어드는 막대가 같은 타이밍 정보를 큰 시각적 이동 없이 보여줍니다 — 스폰·만료 타이밍과 목표 개수는 동일해 난이도는 그대로 유지됩니다.

## 종료 조건과 결말

- **검증 성공**: 6개 웨이브 중 5개 이상 클리어하면 A/S 랭크와 `VERIFIED` 결말을 받고 새 기억 조각과 MORI 파일을 획득합니다. S는 무복구 완벽 런에만 주어집니다.
- **불안정/실패**: 클리어한 웨이브가 4개 이하이면 `UNSTABLE`, `MEMORY INTEGRITY`가 0이면 NULL 랭크로 종료됩니다. 이 경우 새 조각은 지급되지 않습니다.
- **기억 결말**: 결과와 성공으로 얻은 기억 조각을 게임 쿠키에 남기고 다시 플레이합니다. 다음 일지와 문제에 이전 상태가 등장합니다.
- **최종 기록**: 여섯 번째 조각을 얻으면 `MORI.LOG/06`과 `ARCHIVE COMPLETE` 경로가 열리고, 재접속 인트로는 최고 점수와 6연속 `SYNC` 도전으로 전환됩니다.
- **무상태 결말**: 게임 쿠키를 삭제하고 첫 방문 상태로 돌아갑니다.

## 실행 방법

### 온라인 플레이

- 플레이 링크: <https://softkleenex.github.io/state-less-game/>
- 플레이 영상: **업로드 후 YouTube URL 입력**

### 로컬 실행

Node.js 20.19 이상이 설치된 환경에서 다음 명령을 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시된 주소를 Chrome, Edge, Safari 또는 Firefox 최신 버전에서 엽니다. 최신 Cookie Store API가 없는 환경도 `document.cookie` 폴백으로 플레이할 수 있습니다.

## 데이터와 접근성

게임 쿠키에는 방문·완료 횟수, 점수, 결말, 조각, 보존 정책만 저장하며 개인정보·타 사이트 쿠키는 읽지 않습니다. 키보드·스크린 리더·움직임 감소를 지원하고 탭 이탈 시 타이머를 멈춥니다.
